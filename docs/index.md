# Transport for London (TfL) MCP Server

Welcome to the **TfL MCP Server** documentation.

This is a Model Context Protocol (MCP) server that exposes the [TfL (Transport for London) Unified API](https://api.tfl.gov.uk/) as tools, allowing AI assistants like Claude to query live London transport data.

## What is MCP?
The Model Context Protocol (MCP) allows AI models to securely interact with local or remote APIs, databases, and services to ground their responses in real, up-to-date data.

## Features
With this server, your AI assistant can:
- Check the real-time status of the Tube, Overground, and Elizabeth lines.
- Find live arrivals at specific bus stops or train stations.
- Plan journeys across London using public transport.
- Check live Santander Cycles (Bike Point) availability.
- Discover real-time road and line disruptions.
- Check current London Air Quality data.

To learn how to install and connect this server to your AI assistant, check out the [Installation Guide](installation.md).
